# Hardware, Networks & AI Behaviour — Study Book

**[Open the complete book](Study%20Book.md)**

The same complete content is also available in [markdown_content/learning-materials.md](../markdown_content/learning-materials.md), alongside the [Markdown folder guide](../markdown_content/README.md).

Read one book from beginning to end, with numbered chapters and subchapters, a clickable contents page, worked examples, review questions, glossaries, sources and image credits. The robot vacuum connects the three core subjects; the light indicator provides a practical hardware project.

Start with Chapters 1–6. Read Chapter 8 before attempting the Chapter 9 circuit. Detailed circuit and Q-learning calculations are extensions, not prerequisites for the beginner [practice bank](../Test%20Bank/Questions.md). Its [answers](../Test%20Bank/AnswerKey.md) explain the reasoning.

## Supporting files

The `Hardware`, `Network` and `AIBehaviour` folders contain the original chapter sources, diagrams, Arduino sketches, research notes and review records. The root `markdown_content` folder contains the newer six-lesson source drafts. These are supporting authoring files; **Study Book.md is the single reading edition**. Existing PDFs are older source exports, not exports of the consolidated book.

See [Book Sources.md](Book%20Sources.md) for the consolidation map and maintenance instructions. Review and physical-build limitations remain recorded in the original sources; consolidation does not establish that those checks were completed.
